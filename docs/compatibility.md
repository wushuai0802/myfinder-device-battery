# 通用版兼容范围

目标是让兼容清单内的设备接上就用：自动枚举、匹配内置读取器并生成卡片，不让最终用户填写协议参数、安装Python或录制USB数据。

当前设备范围以文末自动生成的读取器目录为准，另有原有ATK A9 Air+与HyperX Cloud Alpha Wireless专用读取。没有统一协议能覆盖所有2.4G外设；以下是协议/型号族范围，不是市场占有率统计，也不等于每个变体均已实测。

机器可读验证来源为[兼容目录](../engine/compatibility.json)，详情页使用同一来源。本项目已经取得历史实机证据的确切原生配置标A；通用读取器整体保守标C，按型号另列证据。F505接收器有本项目维护者单次实机对照（A级历史证据），不升级同族其他型号；充电/休眠仍未测。上游记录不会自动升级为本项目实测。INFI75标D，当前不宣称兼容。

VGN `320F:5088` 键盘接收器另有维护者2026-11-05单次实机读数93%（VGN HUB为94%），标A历史证据；充电未知，休眠/唤醒仅部分观察。同 ID、同产品串 `Wireless Gaming Keyboard` 的 Rainy75（#23）未验证，不宣称兼容；无法仅凭这些信息区分，可能收到相同只读查询，格式不符不显示读数。

## 数据和设备控制

- 设备报告百分比时显示原值；只有档位或电压估算时标为“约值”，不捏造1%精度。
- 未返回电量时显示未知或带原时间的缓存；缓存不声明设备在线，也不触发低电量提醒。
- Windows蓝牙属性显示“系统提供 · 最近查询”；本次缺少属性时沿用原读数时间，不伪造设备测量或充电证据。
- 同型号接收器按物理实例区分，Logitech槽位保持独立；跨读取器只在具有可靠设备单元证据时合并。同一读取器、同类型、不同且非空物理连接、电量差不超过5，且名称相同或包含通用接收器名称时，若至少一条不是当前读数，界面暂时隐藏旧连接。两条都是当前读数时全部保留；都不是当前读数时保留最近确认的一条，相同时间按设备 ID 固定选择。原生 ATK 与原生耳机不参与，缓存与读取目标不删除。
- 已知代价：两只同名鼠标电量接近、其中一只正在休眠时，休眠那只会暂时隐藏，动一下并恢复读数就会恢复显示。“状态与诊断”的摘要显示“已隐藏的重复连接”，便于报告误判；固定的托盘设备被隐藏时沿用现有可用设备回退。
- 通用设备以电量监控为主。DPI、麦克风与音源等控制按已验证能力显示，不能只凭同品牌名称开启控制项。
- Logitech PRO X Wireless（C547接收器）支持独立当前DPI读取和快捷切换；HID++ 0x2201支持范围通过设备读取。“快捷DPI”不代表板载档位，不改写0x8100配置或切换板载模式。
- 精确名称`G Pro Wireless Gaming Mouse`的DPI控制：**已开放，待用户实测**。无线仅限已列明的Lightspeed接收器`C539/C53A/C53D/C53F/C541/C545/C547/C54D`；插线槽位`0xFF`须有现有HID++长集合路径和可复核的非零单元ID，缺失时不开放。仅按设备支持范围做`0x2201`易失写入，写前复核身份与当前值、写后读回、不重试、不写板载配置。其他型号、名称差异及未列明接收器不开放；本次用户设备的接收器PID、插线单元ID可靠性及实际读写仍待实机确认。
- USB鼠标活动补读仅在Windows能可靠确认USB物理来源时启用，按接收器范围合并；共享接收器的多个槽位仍独立保留设备身份。活动不代表成功取得电量，也不会为未支持型号启用新厂商命令。蓝牙与无法可靠分组的来源继续使用原有系统属性、事件和定时读取。
- 存在厂商驱动独占设备、休眠、固件变体等情形时，接收器存在不代表电量当前可读。新增型号由维护端补充读取器，最终用户不用调报文。

ATK A9 Air 用户记录（2026-11-02）：单个用户报告 1.3.5-beta.1 显示的电量正确，仅涉及只读电量。该型号证据等级仍为 C，不将整个 ATK 协议族升级，不开放 DPI；确切 VID:PID、固件与连接集合未随这份读数反馈完整确认，不能据此推广到所有同名变体。

ATK 的协议族匹配仍不保证所有 A9 Air 或同名变体可读：`373B:120A` 的连接方式与集合仍待实测。只有 FF04/FF05 的设备不匹配，输出长度未知或不为17字节时不发送请求。原生 `373B:1278` 继续由专用读取器负责；既有 PID 表行为不变，不放宽 `3554`、`3710`、`3770`，也不为新匹配设备开放 DPI。未回复的动态型号不计为已适配读取器故障；无卡片时可在主动反馈报告中查看型号与集合，休眠也可能导致没有读数。

界面、桥接、安装事务及协议解析均有自动化验证；其他人的实际硬件仍需按型号核验。兼容表会随验证结果更新。

V9 PRO / V9 Turbo+ 的接电状态由读取器输出（Turbo+ 的充电和关机语义沿用 V9 PRO，尚未实测），但当前原生界面仅在有当前百分比时显示充电指示，因此接电时会显示电量未知，尚不显示该指示；完整界面体验仍待后续验证。
